# Film Recipe Lab 0.2.2

Setup now accepts the official GFX ETERNA 55 v1.10 ZIP or an extracted folder.
Use Choose Downloaded ZIP or Choose Extracted Folder. The folder browser also
accepts the F-Log2 subfolder. All ten LUT hashes must match before installation;
original files are preserved. The local installer automatically detects ZIPs
versus directories.

Includes the 0.2.1 Leica DNG color fix. Apple Silicon, macOS 14 or newer.
Ad-hoc signed, not Apple-notarized. Replace the previous app and restart it;
installed LUTs are retained.
